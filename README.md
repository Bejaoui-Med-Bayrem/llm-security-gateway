# LLM Security Gateway

LLM Security Gateway is a security platform designed to test, attack,
protect and evaluate LLM-based applications.

## Project Goals

The platform combines:

- LLM Red Teaming
- Prompt Injection Testing
- Jailbreak Testing
- RAG Security Testing
- Security Gateway
- Risk Scoring
- Security Evaluation
- Attack Campaign Management

## Architecture

The platform is composed of:

- Next.js frontend
- FastAPI backend
- Red Team Engine
- Security Gateway
- Evaluation Engine
- Target LLM Application
- PostgreSQL
- RAG / Vector Store
